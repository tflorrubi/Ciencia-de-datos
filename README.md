## 📖 Sobre el proyecto

Este repositorio contiene diferentes actividades prácticas orientadas al aprendizaje de **Ciencia de Datos con Python**.

Los proyectos abarcan desde la manipulación de estructuras de datos hasta procesos de limpieza, transformación, análisis estadístico y representación gráfica de información.

El objetivo principal es desarrollar habilidades para **convertir datos en información útil mediante herramientas de programación y análisis**.

## 🐼 3. Análisis de Ventas con Pandas

Proyecto de análisis de datos de ventas utilizando **Pandas**.

### 🔎 Procesamiento realizado

```text
Datos CSV
   ↓
Carga de información
   ↓
Limpieza de datos
   ↓
Transformación
   ↓
Análisis exploratorio
   ↓
Agrupación y estadísticas
   ↓
Visualización
   ↓
Conclusiones
```

### 📊 Técnicas utilizadas

* `read_csv()`
* `describe()`
* `groupby()`
* `pivot_table()`
* `merge()`
* Filtrado de información
* Tratamiento de valores nulos
* Análisis temporal
